# Нейрон: Навчання (Neural Network Training Visualizer)

Цей проєкт є міні-додатком для візуалізації процесу навчання простої нейронної мережі (одношарового перцептрона) у реальному часі. Проєкт складається з бекенду на **C++** (який обчислює епохи навчання за допомогою градієнтного спуску) та фронтенду на **Python** з використанням **Tkinter** і **ctypes** для інтеграції та графічного відображення.

---

## 🛠 Збірка бекенду (C++)

Для роботи програми спочатку потрібно скомпілювати C++ файл (`nn.cpp`) у динамічну бібліотеку (`.so`, `.dylib` або `.dll` залежно від вашої операційної системи).

> **Важливо!** Використовуйте оптимізацію рівня `-O2` або `-O1`. Без оптимізації рівня `-O3` (рекомендується саме `-O2`) гарантується коректна поведінка для роботи через `ctypes`.
> * **Windows:** Використовуйте **MinGW** (MSVC не підтримується).
> * **Linux:** Використовуйте `Clang++` або `G++` (під WSL найкраще підходить `G++`).
> 
> 

### Команди для збірки:

* **Linux:**
```bash
g++ -O2 -shared -fPIC nn.cpp -o libnn.so

```


* **macOS:**
```bash
g++ -O2 -shared -fPIC nn.cpp -o libnn.dylib

```


* **Windows (MinGW):**
```bash
g++ -O2 -shared nn.cpp -o nn.dll

```

## 📦 Вимоги та запуск

### 1. Системні вимоги

* Python 3.x
* Встановлений пакет `tkinter` (зазвичай йде в комплекті з Python на Windows/macOS; на Linux встановлюється через пакетний менеджер, наприклад, `sudo pacman -S tk` в Arch Linux).

### 2. Запуск додатка

1. Покладіть скомпільовану бібліотеку (`libnn.so`, `nn.dll` або `libnn.dylib`) в одну паріку з Python-скриптом.
2. Запустіть скрипт:
```bash
python <ім'я_скрипта>.py

```

## 🚀 Як користуватися додатком

1. **Параметри налаштування (верхня панель):**
* Введіть вхідні дані `x` та `y`, цільове значення (`відповідь`), швидкість навчання (`lr`), максимальну кількість епох та поріг помилки (`поріг помилки`).
* Натисніть кнопку **«Нова модель»**, щоб ініціалізувати нові випадкові ваги та запустити розрахунок епох у C++ бэкенті.


2. **Керування відтворенням:**
* **«Крок»** — перехід до наступної епохи навчання.
* **«Старт / Пауза»** — автоматичне програвання процесу навчання з заданою затримкою (регулюється повзунком «затримка, мс»).
* **«В кінець»** — миттєвий перехід до фінальної епохи.


3. **Візуалізація:**
* **Графічна схема нейрона:** показує поточні ваги (`w0`, `w1`), зміщення (`bias`) та обчислене передбачення.
* **Графіки:** демонструють зміну передбачень (порівняно з цільовим значенням) та зменшення помилки з кожною епохою.


4. **Перевірка моделі:**
* У нижній панелі ви можете ввести довільні значення `x` та `y` і натиснути **«Передбачити»**, щоб перевірити, як навчена модель реагує на нові дані за допомогою експортованої функції `nn_predict`.
