# Визуализатор обучения нейросети (Neural Network Training Visualizer)

Этот проект представляет собой мини-приложение для визуализации процесса обучения простой нейронной сети (однослойного перцептрона) в реальном времени. Проект состоит из бэкенда на **C++** (который вычисляет эпохи обучения с помощью градиентного спуска) и фронтенда на **Python** с использованием **Tkinter** и **ctypes** для интеграции и графического отображения.

---

## 🛠 Сборка бэкенда (C++)

Для работы программы сначала необходимо скомпилировать C++ файл (`nn.cpp`) в динамическую библиотеку (`.so`, `.dylib` или `.dll` в зависимости от вашей операционной системы).

> **Важно!** Используйте уровень оптимизации `-O2` или `-O1`. Чтобы обеспечить корректную работу через `ctypes`, избегайте уровня `-O3` (рекомендуется именно `-O2`).
> * **Windows:** Используйте **MinGW** (MSVC не поддерживается).
> * **Linux:** Используйте `Clang++` или `G++` (под WSL лучше всего подходит `G++`).
> 
> 

### Команды для сборки:

* **Linux:**
```bash
g++ -O2 -shared -fPIC nn.cpp -o libnn.so

```


* **macOS:**
```bash
g++ -O2 -shared -fPIC nn.cpp -o libnn.dylib

```


* **Windows (MinGW):**
```bash
g++ -O2 -shared nn.cpp -o nn.dll

```

## 📦 Системные требования и запуск

### 1. Системные требования

* Python 3.x
* Пакет `tkinter` (обычно поставляется вместе с Python на Windows/macOS; на Linux устанавливается через пакетный менеджер, например, `sudo pacman -S tk` в Arch Linux).

### 2. Запуск приложения

1. Положите скомпилированную библиотеку (`libnn.so`, `nn.dll` или `libnn.dylib`) в ту же директорию, где находится Python-скрипт.
2. Запустите скрипт:
```bash
python <имя_скрипта>.py

```

## 🚀 Как пользоваться приложением

1. **Параметры настройки (верхняя панель):**
* Введите входные значения `x` и `y`, целевое значение (`відповідь`), скорость обучения (`lr`), максимальное количество эпох и порог ошибки (`поріг помилки`).
* Нажмите кнопку **«Нова модель»** (Новая модель), чтобы инициализировать новые случайные веса и рассчитать эпохи в C++ бэкенде.


2. **Управление воспроизведением:**
* **«Крок»** (Шаг) — переход к следующей эпохе обучения.
* **«Старт / Пауза»** — автоматическое воспроизведение процесса обучения с заданной задержкой (регулируется ползунком «затримка, мс»).
* **«В кінець»** (В конец) — мгновенный переход к финальной эпохе.


3. **Визуализация:**
* **Графическая схема нейрона:** отображает текущие веса (`w0`, `w1`), смещение (`bias`) и вычисленное предсказание.
* **Графики:** показывают изменение предсказаний (по сравнению с целевым значением) и уменьшение ошибки с каждой эпохой.


4. **Проверка модели:**
* На нижней панели вы можете ввести произвольные значения `x` и `y` и нажать **«Передбачити»** (Предсказать), чтобы проверить, как обученная модель реагирует на новые данные с помощью экспортированной функции `nn_predict`.
